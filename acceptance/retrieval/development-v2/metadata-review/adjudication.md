# Development-v2 metadata adjudication — review proposal

Status: pending source cross-review and P2 governance-owner review. No executable
record or effective approval is asserted here. The frozen factual sources and
independent passage judgments remain unchanged.

1. Distinguish source standing, fixture-record lifecycle, and subject approval.
A source may be unreviewed while a reviewed record accurately states that fact.
Neither record verification nor accepted classification approves a proposed
external action. A later fixture curation Decision must name what it reviews;
no source-owner approval or live human review is inferred.

2. Record IDs in the source-attribution inventory are provisional allocations,
not proof of accepted publication. Unaccepted records use the actual target
proposal identity path. A historical source can quote D-000007 without that
string becoming an allocated runtime key. Do not introduce old/new lookup or
persist a source-ID-to-proposal runtime registry. Source locators, kind and actual
record identities remain independently visible to the evaluator.

3. Classification is authored metadata. Sources warrant topics and semantics;
they need not literally print the taxonomy. Review the deep engineering forest
for valid broader/narrower meanings and material warrant. Do not flatten merely
because the source did not spell parent edges, and do not keep questionable
edges merely to achieve depth. Every organization owns its own registry.

4. Explicit empty assignments can be authored by a reviewed fixture curation
Decision. They mean a known empty recorded set, not exhaustive semantic absence.
This requires a declared metadata decision and cannot be inferred from silence.
Preserve explicitly missing classification as absent. Do not fill those cases
with obvious subjects merely because a reviewer can infer the topic.

5. Preserve source applicability without importing scope from neighboring
artifacts. Missing country/client/release is unknown; baseline empty lists are
legacy unrestricted defaults, not verified universality. Current P4 applicability
profiles remain pending. Source-based scope proposals must not be presented as
an executable filtering contract.

6. Multi-section records can have multiple topic assignments. Query conjunction
means recorded co-membership, not a joint source claim. Preserve independent
scope components and jointWarrant:false in the semantic review. Do not strip
valid classification to hide notebooks from retrieval.

7. D-000006 supersedes West VIP policy only. D-000002/3 remain competing accepted
ordinary-ticket rules; do not mark them globally superseded or infer precedence
from dates. Encode a scoped relationship only when the actual runtime supports
it; otherwise preserve the limitation and explicit source text.

8. Existing 48 passage judgments remain the evidence target. Record-level grades
can be projected only after source-to-record fidelity and actual record identity
are reviewed. New support/governance records consume inspection budgets and
require explicit grading; do not pretend they were in the original denominator.

9. Synthetic fixture review uses real capture, ledger and P2 evaluation paths.
It does not authenticate human identity or approve live source changes. Runtime
validation, reviewed source facts, agent answers and numeric retrieval scores
remain separate evidence.
