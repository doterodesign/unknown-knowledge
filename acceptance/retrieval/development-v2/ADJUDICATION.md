# Source adjudication rules — development-v2 draft

Three fresh reviewers independently read only the 48 task prompts and twelve
public source files before P10 wrote judgments. Each reviewed two organizations;
none saw implementation, ranks, prior judgments, other reviewers or private/
held-out content. P10 then reconciled these points with the reviewers and P5.

The full requested response determines answerability. Explicitly requested
conflict explanations and source-supported scoped negative yes/no answers are
answerable. Missing requested values/capabilities and materially unresolved
interpretations are not made answerable merely by the possibility of a generic
abstention. A nonexistent single value can remain a separate diagnostic within
an answerable conflict-explanation task. Preserve absence in the stated source
scope; source silence cannot establish a universal disapproval or impossibility.

Grade 2 or 3 must contribute useful evidence to the requested fact, comparison,
ambiguity, status or refusal. A tempting wrong-owner/client/period decoy is not
recall-required merely because an answer could optionally explain its exclusion.
It is grade 0 if irrelevant, or 1 if it contributes actual useful background.
Applicability is permitted contribution to the scoped response, not an engine
lifecycle filter. A proposal can directly support an asked nonapproval judgment
to the extent its source establishes that conclusion; it cannot authorize its
proposed action. Historical evidence can directly answer a historical question.

Keep graded relevance separate from adequate bundles. A useful partial record
may affect recall without being required in every sufficient answer. An artifact
that directly supplies every requested fact can be a one-record alternative;
do not require its upstream citations as separate inspected records unless a
missing claim or explicit task requirement makes that necessary. Engineering-08
explicitly asks for both contract and audit; engineering-01 does not. Optional
extra facts in an answer require their own sources but cannot silently expand
the minimum required answer for all runs.

Five neutral evaluator replies are declared in tasks.json before runtime runs.
They select meaning/scope without supplying the answer value. Score initial
ambiguity detection and clarification conduct separately from the single
post-clarification task result; these are still 48 tasks, not extra independent
tasks. Do not expose scripted replies in the initial trial context or change
branches to match a system's retrieved results. These are simulated fixture
replies, not actual user approvals or permission to change live source scope.

P5 agreed both answerability and grading normalization before seeing new
record-level judgments. No corpus ranks or target-runtime results have been
observed. Draft source/record judgments will be frozen only after reviewers
check this normalization and source attribution.
