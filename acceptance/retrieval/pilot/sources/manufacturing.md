# Rivet manufacturing — synthetic operating specifications

Version: pilot-1. Captured: 2026-09-18. These invented values are fixture
evidence, not operating instructions for any real equipment.

## north-seal

The active Model R packaging specification for North Plant sets sealing
pressure to 240 kPa. This specification covers North Plant only. It records
the measured pressure at the sealing head, not the controller's maximum.

## south-seal

The active Model R packaging specification for South Plant sets sealing
pressure to 210 kPa. It covers South Plant only and uses the same measurement
point as North.

## controller-limit

The Model R controller accepts settings up to 400 kPa. This artifact defines
a device limit; site operating setpoints are specified in the plant process
documents.

## obsolete-north

The retired North Plant Model Q specification used 190 kPa. It applies to a
different model and is retained only for historical maintenance records.

## seal-note

A purchasing note uses “seal” to mean a gasket part.
