Deprecating a release retires it from the library while already-placed instances
keep rendering. The release moves to `deprecated` in `ReleaseStatus`
(`src/types/release-status.ts`), which is a terminal state: no later publish
rewrites it. Because the guidance tracks the library's weekly release train,
this leaf is declared `volatile` — its claims rot fast, and the planted stale
date is what proves the Time facet fires (UCS-1150).
