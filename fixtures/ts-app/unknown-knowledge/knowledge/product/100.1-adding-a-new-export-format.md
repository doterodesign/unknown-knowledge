Adding an export format is a one-line registry change plus the matching ontology
update. Add the format's key to `EXPORT_FORMATS` in
`src/registry/export-formats.ts`, then update concept K-101's
`enumerates.values` in the same PR — the value validator diffs the two both ways
and blocks on any mismatch.
