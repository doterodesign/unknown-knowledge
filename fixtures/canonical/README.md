# Canonical test fixture

The one shared fixture for engine tests: eight installations from the
development-v2 retrieval corpus, committed as plain files. `records.json` maps
every record to the source passage the gold judgments in
`acceptance/retrieval/development-v2/source-judgments/` grade, which is what
`tests/ask-gold.test.js` scores retrieval against.

Use it through `tests/helpers/canonical.js`:

- `installation(name)` for read-only tests, in place.
- `copy(t, name)` for tests that edit files.
- `repository(t, name)` for tests that need Git. The first commit is made once
  per test process and copied for each test.
- `scratchRepository(t, files)` for tests whose scenario is a planted tree
  rather than a store (a survey blind spot, an audit candidate). The empty
  repository is initialized once per process and copied.

Do not edit these files to make a test pass. They were generated by
`acceptance/retrieval/materialize-development.js` and the gold judgments refer
to them; regenerate them from there if the corpus changes.
