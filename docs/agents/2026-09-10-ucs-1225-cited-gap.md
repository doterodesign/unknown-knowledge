## Scope

The existing engine already supplies the required capture helper, draft
preflight, catalog/typed references and derived checks. This change clarifies
capture and kb-build orchestration and supplies a reproducible A5 walkthrough.
It does not add an intake system, change ranking, expand the taxonomy, or claim
that structural validation certifies a human's review.

The new derivation example exposed a protocol-test side effect: the flag probe
ran `derive --write` in the kit checkout. It created `knowledge/derived`, which
made dogfood validation fail because there was no knowledge catalog. The probe
now runs each command in a disposable directory with cleanup. This was observed
before the fix, then the same focused protocol checks passed without leaving a
knowledge directory. Engine production code is unchanged.
